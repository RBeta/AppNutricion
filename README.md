# AppNutricion

Registro diario de consumo para Rubén y Sarai.

## Contenido

- `web/dist`: aplicación web instalable (PWA) actualmente publicada.
- `android`: borrador nativo inicial para Android.

La aplicación web no requiere compilación: abre `web/dist/index.html` mediante un servidor estático o publícala como sitio estático.
