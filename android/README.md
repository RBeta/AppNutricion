# Registro de consumo para Android

La aplicación permite seleccionar el plan de Rubén o Saraí, elegir una fecha, marcar los grupos consumidos por comida y reiniciar únicamente el día seleccionado.

Para generar el APK, abre la carpeta `registro-consumo-android` en Android Studio y usa **Build > Build APK(s)**. El APK de prueba queda en `app/build/outputs/apk/debug/app-debug.apk`.

Requisitos: Android Studio reciente, JDK 17 y Android SDK Platform 35.
